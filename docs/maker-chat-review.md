## 5. 关键口径的演进（改错过 / 被反复订正的）

1. **扣血规则**：整船扣血 → 按飞船组移动 → **每行方块独立碎裂、各自 0.5 血向上取整，升级加成只作用在合计后的数字**（08-16 → 09-10）。
2. **透视**：自由 3D → 禁止平行透视 → **正交 + 俯视偏正视 20°（标定 46°）**，且视觉模型不得超出权威碰撞范围。
3. **游戏名**：燃烧的蔬菜（否）→ 太空飞机弹珠 → 击碎，飞机大战 → **货车大战飞机**（改名必须连字标图一起换）。
4. **车辆来源**：四色换装 → **六款不同车型**（允许跑车/越野车等）。
5. **开局车与解锁**：固定送加速车 → 天赋树解锁 ≠ 开局可用（三层门控）→ 分裂车天赋开局解锁 → **新档开局四车首阶全解锁 + 每关两轮「只出车辆解锁卡」三选一**（10-14，替代前面所有开局约束）。
6. **变现形式**：只广告 → 接受「单机间接联机」解锁内购（服务端只发货与权威余额），但**禁止任何形式的平台默认联机大厅 UI**；广告触点从 5 种被整体否决收敛到 ≤3-5。
7. **UI「贵」的语义**：层次 → 自身风格 → 温度（暖金）→ 纹路密度，四次不是同一件事，不能互相替代。
8. **蓄力全息**：透明度/倍率/停留时长被连发 6 条逐步收敛（40% → 80%；「.5 倍」→ 按 1.2/1.5 倍实现；发射后才开始消散 → 2s 停留 + 3s 淡出），且明确「拖拽圆是 2D 屏幕空间的圆投影」。

## 7. 重取方法（原始逐条）

1. 右侧浏览器打开 `https://maker.taptap.cn/app/967d6b58-e8f0-4579-9c6a-7385f929080e?chatId=<chatId>`（需已登录）。
2. 页面上下文内带 `Authorization: Bearer <localStorage.taptap_access_token>` 请求：
   - `GET /api/v1/apps/<appId>/chats?limit=300` → 全部会话（id / title / createdAt / lastActivity / agentModelConfigCode）
   - `GET /api/v1/chats/<chatId>/prompts?limit=500` → 该会话的开发者输入原文（`params.prompt[].text`、`timestamp`(ms)、`chatRound`）
   - `GET /api/v1/chats/<chatId>/messages?limit=200&before=…&until=…` → 含 Agent 侧 JSON-RPC 事件流（量极大，慎拉）
3. 时间戳是 ms epoch，按 UTC+8 展示；`prompts` 只含开发者输入，**不含 Agent 回复**，Agent 结论要看 `/messages` 或本地 `docs/versions.md`。
