# P12 · 美术精细度与视听表现开发计划书（对标一线大作视听打磨）

> 版本：v0.9.0 规划 / 草稿 v1
> 模块方向：PBR 材质细化、粒子系统、受击/死亡动画、动态光照、屏幕动效（juice）、音频空间化
> 目标读者：负责 `Renderer3D.lua` / `Scene3DBackend.lua` / `Presentation.lua` 视听表现的开发者

---

## 一、模块目标与诚实定位

一线大作（如《原神》）的「美术精细度」来自：PBR 材质分层、基于物理的光照、骨骼动画、粒子与后效、镜头语言、音频空间化。本游戏是体素 + NanoVG 工程风，风格化路线，不与写实大作比「拟真度」，而比**风格化精致度与 juice 密度**——这正是《陷入了深渊》《二十分钟傻傻英雄》等体素肉鸽的取胜点：用有限的几何，靠材质、粒子、动效、音画同步把「廉价体素」做成「有质感的风格化画面」。

本模块目标：把当前「单 CustomGeometry 面+棱线、冻结仅变色、越线仅微震」的朴素表现，提升到**风格化一线水准**——分层 PBR 材质、程序化粒子、打击顿帧、受击闪白、死亡碎裂、动态光反馈、屏幕 juice、空间化音频。所有提升严守「渲染只读快照、体素单 CustomGeometry、FXAA 禁用、WORLD_SCALE 统一」四项硬契约。

---

## 二、精细度缺口与提升路径

### 2.1 材质细化（PBR 分层）
当前敌方 6 section（面/侧围/轮胎/金属/玻璃/灯光）为基础 PBR。提升：① 主车漆加**清漆层**（clearcoat 近似，用第二 PBR 层或 emissive 边缘光）增强质感；② 浅色侧围用**顶点色 AO** 模拟接缝阴影（AB-016 浅色因子深化）；③ 玻璃用半透 PBR + 环境反射近似（无实时反射，用 cubemap 近似，见 `convert-panorama` skill 生成天空盒）；④ 轮胎用程序化噪点纹理（`run-lua-headless` 离线烘焙，AB-003 资源验证）。

### 2.2 粒子系统（程序化）
当前碎片为简单色块。提升为**GPU 友好粒子池**（P9 T3 对象池复用）：① 砖块碎裂 = 多面体碎片 + 火花 + 冲击环；② 弹珠拖尾 = 速度场粒子（P2 T5 渐隐升级为粒子而非单纯几何）；③ 冰冻 = 霜晶生长粒子；④ 燃烧（P11 T2）= 火焰舔舐 + 余烬上升；⑤ 升级 = 能量汇聚光束。粒子参数由 `Presentation` 维护（瞬时状态），渲染只读。

### 2.3 动画与 juice（打击感）
① **受击闪白**：砖块受击瞬间顶点色向白偏移 0.08s（规则层 `Emit("hit")` 驱动 `Presentation` 计时）；② **死亡碎裂**：brick.alive=false 触发碎裂粒子 + 0.05s 全局顿帧（hitstop，仅视觉，不影响规则 tick）；③ **发射挤压**：车辆待发射时车体轻微缩放挤压（AB-014 朝向追踪协同）；④ **升级扫光**：P10 T5 扫光升级为沿卡片扫过的能量带；⑤ **镜头 juice**：越线震屏（P2 T2）加轻微旋转抖动，Boss 出现加镜头推近（短暂，不破坏 46° 投影契约）。

### 2.4 动态光照与后效
① **受击点光**：砖块受击在 3D 层生成短暂点光（PointLight，受 P9 光源数护栏）；② **防线脉冲光**：越线时防线点亮（P2 T2 材质脉冲升级为发光）；③ **后效**：FXAA 在本环境禁用（AB-008），但可启用 **Bloom（受控）** 与 **Vignette**——前提是验证环境允许（需 T6 探测，禁止盲目开导致黑屏）；④ **色调映射**：ACES 近似，提升工程风深紫的层次。

### 2.5 音频空间化（P10 协同）
① **3D 音源**：弹珠/敌机音效按世界坐标衰减（SoundSource3D），近大远小；② **Boss 低频**：Boss 出现加环境低频铺底；③ **音乐动态层**：BGM 按波次/血量叠加入层（intensity layer），与 P6 节奏联动；④ **玩家反馈音**：升级/越线/击破各有辨识音（P10 T2）。

## 三、架构切面与契约坚守

- `Renderer3D`：材质/PBR 分层、粒子渲染、点光、受击闪白顶点色、顿帧（仅视觉 timer）。只读 `GetSnapshot`/`Presentation`。
- `Scene3DBackend`：Bloom/Vignette 探测开关、色调映射、镜头 juice（震屏/推近，位移后 `RefreshProjection` AB-026）。
- `Presentation`：所有瞬时状态（hitFlash/碎裂/冻结/升级/防线脉冲）的计时与参数，供渲染与音频消费。
- `Game`：只 `Emit` 事件，不控制任何视觉（AB-027）。
- 资源生成：`run-lua-headless` 烘焙噪点纹理、`convert-panorama` 生成 cubemap、`text_to_sound_effect`/`text_to_music` 生成音频（P10）。

## 四、具体任务清单

### T1：PBR 材质分层
主车漆清漆层、侧围顶点 AO、玻璃 cubemap 近似反射、轮胎程序化噪点（headless 烘焙）。维持单 CustomGeometry 多 section（3D 体素性能契约）。

### T2：粒子系统升级
碎裂/拖尾/冰冻/燃烧/升级五类粒子池（P9 T3 复用）。参数由 `Presentation` 维护，渲染只读。

### T3：打击感 juice
受击闪白（顶点色）、死亡碎裂粒子 + hitstop（视觉 timer）、发射挤压、升级扫光带、镜头推近（不破坏 46° 投影）。

### T4：动态光照
受击点光（受 P9 光源护栏）、防线脉冲发光、受控 Bloom/Vignette（AB-008 探测）、ACES 色调映射。

### T5：音频空间化
SoundSource3D 按坐标衰减、Boss 低频铺底、BGM 动态层、辨识反馈音（P10 协同）。

### T6：后效探测护栏
`Scene3DBackend` 初始化探测 Bloom/Vignette 是否导致黑屏；仅在不复现 AB-008 失败特征时启用，否则降级无后效（绝不盲目开 FXAA）。

## 五、风险与避雷

- **禁止渲染层算规则**：所有伤害/状态在 `Game`，渲染只读（AB-027 / 视觉瞬时状态契约）。
- **禁止每体素/每粒子 Node**：粒子走对象池、体素单 CustomGeometry（3D 体素性能契约 / AB-009 / P9）。
- **禁止破坏 VCol**：顶点色仍 VCol + 白基底（AB-007）；闪白在顶点色上做，不换材质。
- **FXAA 禁用红线**：T6 绝不启用 FXAA，Bloom/Vignette 需探测（AB-008）。
- **投影契约**：镜头推近/旋转必须刷新投影缓存，输入与 3D 同帧对齐（AB-026）。
- **WORLD_SCALE 统一**：光照/粒子世界尺寸经 `WORLD_SCALE`（v0.9.0 体素契约）。

## 六、验收标准

1. 材质有清漆/侧围 AO/玻璃反射/轮胎噪点，仍单 CustomGeometry（T1）。
2. 五类粒子池复用、无逐粒子 Node（T2，P9 协同）。
3. 受击闪白 + 碎裂 + hitstop + 挤压 + 扫光 + 镜头 juice，均视觉 timer 不卡规则（T3）。
4. 点光/防线发光/受控 Bloom-Vignette/ACES 生效且不黑屏（T4，AB-008）。
5. 3D 音源衰减、Boss 低频、动态 BGM 层（T5，P10 协同）。
6. 后效探测护栏防黑屏（T6）。LSP 0 Error + 官方构建通过；渲染层无 `Game.` 写入。

## 七、对标诚实结论

在**风格化精致度与 juice 密度**上，本模块可把体素工程风做到《陷入了深渊》《元气骑士》之上的「有质感的太空工业风」：分层 PBR、粒子、打击顿帧、动态光、空间化音频，这些是一线大作「手感好」的真相。但在**写实拟真度、骨骼动画、开放世界光照规模**上，体素风格化路线不可能也不应与《原神》比——那是不同美术哲学。正确策略是：用风格化极致打磨 + 系统密度（P11）构成「小而深、精而 juicy」的体验，在肉鸽幸存者赛道对标一线，而非在写实规模上硬碰。本环境验证限制（FXAA 禁用、无 headless 截图）要求所有后效必须经探测护栏，宁可降级也不黑屏。

## 九、风格化对标定位再确认

我们不与《原神》比写实规模，而比「风格化精致度」。体素 + 工程风的劣势（几何简单）恰是优势：相同算力可堆更多粒子、更密光照、更强 juice。参考《陷入了深渊》用体素 + 强粒子做出「脏朋克」质感，本游戏可用「深紫工业 + 淡蓝工程线 + 明紫强调 + 碎裂粒子 + 受击顿帧」做出「太空防线」的紧凑质感。美术精细度的真相不是多边形数，而是：材质分层、粒子密度、光照反馈、动效节奏、音画同步——这五点本模块全部覆盖，且经 P9 性能护栏保证不卡顿。在肉鸽幸存者赛道，这套组合足以达到一线大作的「手感精致度」。
