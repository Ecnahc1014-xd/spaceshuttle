# 跨项目抗体清单

> 从历史项目中积累的通用踩坑经验，跟随 skill 旅行到新项目。
> POST-3 同步时，仅写入标记为 [跨项目] 的避雷条目。

## 通用抗体

- [AB-001] [并发编辑] 工具写入后若文件内容或时间戳再次变化，必须重读并合并会话外修改，禁止以旧上下文覆盖。（燃烧的蔬菜/v0.2.0）
- [AB-002] [游戏分层] 权威玩法随机流与渲染随机流必须隔离，否则不同帧率或后端会改变玩法随机结果。（燃烧的蔬菜/v0.2.0）
- [AB-003] [运行验证] 验证器的 engine shader cache 报错不能等同 Lua 失败；应分别核对 lua_errors、resource_errors，并以真实渲染截图交叉验证。（燃烧的蔬菜/v0.2.0）
