# 「高光时刻」关卡结算动效 · 科幻版提示词（v1.0）

> 这是本动效的唯一需求源。代码实现必须逐条满足；改动先改这份提示词，再改实现。

## 1. 世界观与风格

- 题材：与游戏一致的 **dark-tech 空战后勤**——货车把补给舱运到前线，关卡清场后回收空投舱。
- 色板（禁止大面积青绿）：
  - 石墨底 `#090A0D` / 面板 `#0E0F13`
  - 银白主操作 `#E2E4E8`
  - 琥珀金（稀有/付费语义）`#F3A73E`
  - 绿 `#2EE86B`（仅广告语义，本页不用）、红 `#E84C4C`（仅错误语义，本页不用）
- 造型语言：硬朗机加工面 + 工艺倒角（圆角只出现在实体边角，不做圆胖卡通）。
- 统一深色描边 `#0A0C12`。

## 2. 等级阶梯（稀有语义：银 → 蓝 → 紫 → 金）

| 档位 | 名称 | 主色 | 亮部 | 暗部 |
|---|---|---|---|---|
| 常规 | SECTOR CLEARED | `#C9D2E0` | `#F4F7FF` | `#5A6474` |
| 稀有 | RARE SALVAGE | `#5B93FF` | `#BBD4FF` | `#1E4C99` |

每升一档必须同步切换：能量核心 / 能量导管 / 陀螺环 / 推进环 / 警示条 / 轮廓光 / 背景热区 / 标题描边投影 / 评级块 / 徽章 / 光芒扇形。

## 3. 主体：空投补给舱（真 3D）

**必须是实体几何，不允许贴图伪造结构。**

- 舱体 = **下箱体** + **四面围栏**，顶部是**真开口**（开口内可见内腔与能量接口环）。
- 装甲：正面 3×3、左右面 2×3 分块；分块之间是**真实间隙**，缝底再压暗色凹槽条（不许画黑线）。
- 加强肋 ×4 + 肋上螺栓；顶部导轨；四角**斜切护角** + 端面螺栓。
- 侧向散热格栅：真实凹槽条。
- 底部**警示斜纹带**：金 / 黑交替的实体小块（旋转 45° 排布）。
- 顶部四个锁扣座（带发光小灯条）+ 内腔底部能量接口圆环。
- 底部悬浮推进环（等级色发光），舱体不落地。
- **舱盖**：**左右对开**双片装甲盖，各绕**外侧竖轴**向上翻开（约 90°，两扇门竖在舱口两侧），
  ⚠️ 不要做"单片整盖"：整盖无论向后倒多少度，俯视都会变成一大块灰板遮住开口与核心。
  内侧为**不受光的深色内衬** + 3 条发光能量导管 + 结构梁（打开后正对镜头，不能是一片灰白板）。
  内侧必须是不受光深色内衬 + 发光导管，否则会被主光照成浅灰大白板。
- 舱内奖励：低多边形**能量核心**（自发光，持续自转 + 呼吸）、**三轴陀螺稳定环**（各自不同轴旋转）、7 个**悬浮碎片**绕核心公转。

## 4. 材质与灯光

- 着色：`MeshToonMaterial` + **4 阶**渐变贴图；最高阶取 232（不取纯白，保留高光层次，避免过曝）。
- 能量件（核心 / 导管 / 灯条 / 推进环）：不受光的基础材质 + 等级色。
- 三灯：**冷白主光** / **天光 HemisphereLight** / **等级色轮廓光**（颜色向白 lerp 22%，强弱随档位递增，只勾边不染面）。

## 5. 描边（后期边缘检测）

- 渲染两张辅助图：**视线空间法线图** + **线性深度图（RGBA packing）**。
- 合成规则：
  - **外轮廓 2.6px 粗线**（环采样判背景）
  - **零件交界 1.4px 细线**（法线差主导；深度差仅作 18% 辅助，阈值放宽，斜面上不许冒细碎斜纹）
  - 线宽由固定像素半径决定 → 全程粗细一致。
- **1.5 倍超采样**颜色缓冲 + **MSAA 4x**。
- 半透明辅助物（光柱 / 投影 / 粒子）不参与法线与深度 pass。

## 6. 动效时序（7.2s 一个循环）

| 时间 | 事件 |
|---|---|
| 0.00–0.45 | 闭合待机 |
| 0.45–1.30 | 舱盖向后翻开 + **能量火花喷发** + 全屏白闪 |
| 0.95–1.75 | 能量核心升起并放大 |
| 1.75–5.05 | 展示：核心自转、陀螺环多轴旋转、碎片公转、光柱脉动 |
| 5.05–5.55 | 核心收回 |
| 5.55–6.35 | 合盖 |
| 6.35–7.20 | 静置 |

- 待机常驻：整体 ±23° 缓慢左右转（看得到侧面与厚度）+ 升降浮动，投影随高度缩放/变淡（悬浮感）。
- 每轮只喷一次火花（按循环序号去重）。

## 7. HUD 与标题

- 科技 HUD：四角 L 形括号、细网格底、全息扫描线、`Orbitron` 数字字体。
- 徽章：`SECTOR CLEARED / RARE SALVAGE / …`，左侧等级色竖条 + 发光。
- 标题「高光时刻」：粗黑体、`skewX(-7deg)`、八向 `text-shadow` 硬描边 + 双层硬投影；
  **逐字砸入带回弹**（落下过冲 → 回弹 → 落定），每档重播。
- 评级：3 个**六边形能量块**依次弹出，未点亮为暗色。
- 分数：等宽数字滚动到目标值。

## 8. 验收标准

1. 四档截图里等级色**一眼可辨**（核心 / 环 / 标题 / 评级 / 背景热区同时变）。
2. 舱盖向后竖立，开口内侧可见核心；不遮挡标题与底部 HUD。
3. 描边粗细均匀，木纹式的"贴黑线"不存在；斜面上无碎斜纹。
4. 待机旋转时能看到侧面厚度与推进环；投影随浮动变化。
5. 60fps 下无卡顿（稳态几何静态，只有变换与自发光参数在动）。
